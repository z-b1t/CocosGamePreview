# 游戏预览

编辑期使用的游戏预览面板。面板会把场景中的相机渲染到一张离屏贴图上并回传到面板显示，不影响运行时代码，也不会改动场景数据。

## 环境

Cocos Creator 3.8.8，Node.js。

## 构建

```bash
# 3.8.8 的 @cocos/creator-types 尚未发布到 npm，
# 先用编辑器菜单「开发者 -> 导出接口定义」导出到本扩展的 node_modules
npx tsc
```

类型检查还依赖项目的 `temp/declarations/cc.d.ts`（编辑器打开项目时自动生成），入口在 `source/@types/cc.d.ts`。

## 用法

主菜单 `面板 -> 游戏预览` 打开面板。面板上的控件：

- **相机**：场景中全部相机的下拉列表，仅在关闭「完整游戏画面」时生效。
- **分辨率**：直接来自设备管理器（`Editor.Message.request('device', 'query')`），设备管理器里增删设备后点「刷新」即可同步。
- **横竖屏**：交换当前分辨率的宽高。
- **完整游戏画面**：勾选时把场景内所有启用且没有占用目标贴图的相机按 `priority` 依次渲染到同一张图（3D 场景和 UI 都能看到）；取消勾选则只渲染下拉框选中的那一个相机。
- **帧率**：控制预览刷新频率。渲染贴图的最长边固定为 1080，并按所选分辨率等比缩放。

预览图始终以 `object-fit: contain` 的方式显示，因此不管面板拖到多大多小，画面都保持所选分辨率的比例完整展示，不裁切也不拉伸。

## 已知限制

切换预览分辨率只会改变渲染目标的宽高比，编辑器里 `Canvas` 的尺寸仍然是项目设计分辨率，不会像真机那样重新执行一次 UI 适配。所以当所选设备与设计分辨率比例差异较大时，UI 元素的对齐结果可能和真机有出入；3D 相机的视锥部分是准确的。
