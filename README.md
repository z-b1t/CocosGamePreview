# Game Preview

An editor-only game preview panel. It renders the scene cameras into an offscreen texture and sends the encoded image back to the panel, without touching runtime code or scene data.

## Requirements

Cocos Creator 3.8.8, Node.js.

## Build

```bash
# @cocos/creator-types 3.8.8 is not published on npm yet.
# Export it first via the editor menu: Developer -> Export Interface Definition
npx tsc
```

Type checking also relies on `temp/declarations/cc.d.ts` generated by the editor; the reference lives in `source/@types/cc.d.ts`.

## Usage

Open it from the main menu: `Panel -> Game Preview`.

- **Camera**: dropdown of every camera in the scene, used only when "Full game view" is off.
- **Resolution**: comes straight from the Device Manager (`Editor.Message.request('device', 'query')`). Press Refresh after editing devices.
- **Rotate**: swaps width and height of the current resolution.
- **Full game view**: renders every enabled camera without a target texture, ordered by `priority`, into the same image, so both 3D content and UI show up. When off, only the selected camera is rendered.
- **FPS**: controls the preview refresh rate. The render target uses a fixed maximum side of 1080 and scales proportionally from the selected resolution.

The preview image uses `object-fit: contain`, so the selected resolution ratio stays intact at any panel size, with no cropping or stretching.

## Known limitation

Changing the preview resolution only changes the aspect of the render target. In the editor the `Canvas` size still follows the project design resolution and does not re-run the runtime UI adaptation, so UI alignment may differ from a real device when the chosen device ratio is far from the design resolution. The 3D camera frustum is accurate.
